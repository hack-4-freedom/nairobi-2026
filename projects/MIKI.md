# MIKI: Voice-Driven Lightning Payment Verification

This repository contains **MIKI**, a hands-free, real-time auditory payment verification system built during **Hack4Freedom Nairobi 2026**.

MIKI bridges browser-native Bitcoin payments with hands-free audio feedback, enabling visually impaired users, merchants, and hands-free operators to verify Lightning Network transactions instantly without looking at a screen 

---

## Overview

In many real-world environments in Kenya such as busy market stalls, screenless POS kiosks, accessibility-first setups, or hands-free environments; checking a screen to confirm a payment creates friction or is completely inaccessible.

**MIKI** solves this by establishing a direct, event-driven audio loop between a Lightning wallet payment and a voice output module, helping the merchants who are visually impaired access their bitcoin wallets with ease.

1. A payment invoice is generated by the server via Lightning node APIs (LNbits or Alby / LNDHub)
2. The user approves the transaction via a WebLN-enabled extension (like Alby)
3. Upon settlement, the backend verifies the invoice state and triggers instant audio confirmation using speech synthesis
---

## Problem

* **Visual Overhead & Inaccessibility:** Existing payment interfaces rely heavily on visual cues (QR codes, screen popups, green checkmarks), excluding visually impaired users and creating friction in fast-paced retail or hands-free scenarios.
* **Lack of Real-Time Settlement Confirmation:** Traditional banking rails take hours or days to settle, requiring pending states that disrupt seamless audio feedback loops.
* **On-Chain Bitcoin Latency:** Standard Bitcoin base-layer transactions require block confirmations (10+ minutes), making real-time spoken payment confirmation unfeasible.

---

## Solution

MIKI leverages the instant finality of the **Bitcoin Lightning Network** combined with client-side WebLN standards and the native Web Speech API 

* **Instant Verification:** Invoices are settled in sub-seconds over Lightning, allowing backend verification almost instantly.
* **Hands-Free Auditory Feedback:** Uses `window.speechSynthesis` to announce state changes aloud—such as invoice generation, payment prompts, and transaction settlement
* **Zero-Touch Client Flow:** WebLN automatically communicates with injected browser wallet providers (e.g., Alby), eliminating manual QR scanning or copy-pasting during transactions.

---

## Technology Stack

* **Frontend:** JavaScript (ES6+), WebLN Standard, Web Speech Synthesis API, HTML5/CSS3 
* **Backend:**: Rust, Axum, SQLx, MariaDB, BTCPay Server, Bitcoin Lightning Network, REST API (HTTP/JSON), Docker, Railway, Git, GitHub, and Cargo.
* **Lightning Network Integrations:** Alby REST API (`@getalby/sdk`).
